About the UHF RFID Label

Unlike NFC tags — which need to be tapped within a few centimetres — these UHF RFID labels operate in the 860–960MHz band and can be read from roughly 2 metres away using a compatible UHF reader, without needing line-of-sight or individual tapping. This makes them suited for bulk scanning: waving a handheld reader across a shelf of dozens of labelled items reads them all in seconds, unlike NFC which requires one tap per item.

Frequently Asked Questions

Do I need a special reader for this?

Yes — UHF RFID requires a UHF-band reader (handheld or fixed-gate), unlike NFC which any modern smartphone can read. We can point you to compatible reader options on request.

What's the difference between this and your NFC tags?

NFC tags need a phone tap within a few cm and are read one at a time; UHF RFID reads multiple tags simultaneously from up to ~2m away, but needs dedicated reader hardware.

Can these be read by a smartphone?

No — smartphones read NFC (13.56MHz, ISO 14443), not UHF (860–960MHz). You'll need a UHF reader.

Are these reusable?

Each label has a unique EPC that can typically be rewritten; check compatibility with your specific reader/software for rewriting.
